# Mini Loan Origination

Menu-driven console application (Java 17, JDBC, MySQL): customers, loan applications, review and
disbursement workflow, overdue-review and core-banking-push utilities, and 6 SQL reports.

## Project layout

```
miniloan/
|-- README.md
|-- build.ps1             compile  (src\ -> out\)
|-- run.ps1               start the application
|-- config/
|   `-- config.properties DB credentials, product limits, business date, scheduler settings
|-- sql/
|   |-- schema.sql        tables, constraints, seed data
|   `-- reports.sql       the 6 parameterized reports (read at runtime)
|-- docs/
|   `-- TEST_GUIDE.md     12-scenario verification walkthrough
|-- lib/                  put mysql-connector-j-*.jar here
|-- src/com/miniloan/
|   |-- model/            entities, enums, DTOs, exceptions
|   |-- dao/              JDBC persistence, transaction manager
|   |-- service/          business rules, state machine, EMI/FOIR, form generation
|   |-- console/          menu UI and Main
|   `-- utility/          schedulers, CSV export, config, business date, INR formatter
|-- out/                  (generated by build.ps1)
`-- output/               (generated at runtime: CSV exports, application forms)
```

## Requirements
JDK 17+, MySQL 8.0.16+ (CHECK constraints), MySQL Connector/J jar in `lib\`.

## Setup and run (PowerShell, from this folder)

```powershell
mysql -u root -p -e "source sql/schema.sql"       # once; safe to repeat, data is kept
# edit config\config.properties  (at least db.password)
powershell -ExecutionPolicy Bypass -File .\build.ps1
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

## Notes
* Use the scripts: they run from the project folder, so the relative paths in
  `config\config.properties` (`reports.file=sql/reports.sql`, `output.dir=./output`) resolve correctly.
* `run.ps1` passes `-Dconfig.file=config\config.properties`; without it the app looks for `config.properties` in the current folder.
* Limits, FOIR threshold, schedule times and business date are all in the config file; menu option 17 reloads it.
* Verification steps for every required scenario: `docs\TEST_GUIDE.md`.
